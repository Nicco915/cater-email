## 分阶段实施

1. 统一只读工作簿接口（值、公式/缓存存在性、来源坐标），支持真正 BIFF XLS；附件 intake、识别、分类、安全限制、补件全链路均支持，不能只改核心读取器。依赖明确并兼容 Windows 安装。无 Excel/LibreOffice 外部进程依赖。
2. 表格区域和语义字段定位：sheet 名辅助，内容优先；扫描有效区域，允许第56行及多表块；表头别名可配置，大小写/空格/换行/标点规范化及组合表头。已知结构锚点规则处理无标题补充列，禁止仅凭启发式猜测放行。多候选/不完整必须暂停。最终配件调整表优先且须结构验证，不回退原价表。
3. 统一业务模型与核对：数量×单件净重、合计、费用行、MSO/序列号匹配；发票单价不能替代 Total Sales Price；邮件表与附件同时提取、冲突缺失整票暂停。保留历史特殊规则、冻结快照重试及原模板格式保护。
4. 回复正文：成功邮件展示采用sheet、变化字段定位、已执行核对数值、人工重点核对建议。结构变化与实际修正分别列出；首次使用新布局重点提示，后续已确认布局不重复告警。基准为已确认布局，不是上封邮件或未经确认的单次修正。需要持久化则设计显式确认/版本边界，不自动信任未知布局。未确定/冲突不得以人工核对提示替代暂停。核对未执行不得称通过；普通成功保持简短。日志/结果保留字段来源与规则ID，避免泄露正文/秘密。
5. 测试、操作文档、回归。报告完整测试命令、结果、真实样本核对证据、Windows未验证部分和待确认项。
